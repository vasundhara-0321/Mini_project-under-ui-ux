

# 💰 MyBudget – Personal Finance Management App

> A modern mobile UI/UX design concept that helps users track expenses, manage budgets, and understand their spending habits.

---

## 📱 Project Overview

**MyBudget** is a mobile personal finance management app designed to make everyday money management simple, clear, and intuitive.

The application provides users with an easy way to track income and expenses, manage monthly budgets, view transaction history, and understand their financial behaviour through visual insights.

This project focuses on **User Experience (UX), User Interface (UI), and Interactive Prototyping** using Figma.

---

## 🎯 Objective

The main objective of MyBudget is to create a simple and user-friendly financial management experience that helps users:

- Track daily expenses
- Record income and transactions
- Create and manage budgets
- Monitor spending patterns
- Understand financial insights
- Make better budgeting decisions
- Keep their financial information organized

💡 Problem Statement

Many people find it difficult to consistently track their expenses and understand where their money is being spent.

MyBudget aims to solve this problem by providing a simple interface where users can:

Track → Organize → Analyze → Budget

their personal finances in one place.
